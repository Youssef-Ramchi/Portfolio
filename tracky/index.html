Tracky App

Mobile app design for
Vehicle tracking & management.

UX Design, UI Design and Design System

Scroll to Explore

Tracky is a vehicle tracking and management solution combining a mobile app and an admin dashboard. The app allows users to follow their vehicle’s location, monitor its activity, and access management features on the go. The dashboard gives administrators a centralized fleet overview, with tools to monitor vehicles and manage daily operations.

My Role

My contributions and responsibilities in this project

UX UI Designer

Key Responsibilities

  • Collaborated with the client to define the needs of both mobile users and dashboard administrators.
  • Structured mobile navigation around tracking vehicle activity and accessing management features.
  • Applied clear visual hierarchy to maps, activity details, and alerts.
  • Organized the admin dashboard to provide fleet oversight and access to key management tools.
  • Maintained consistent UI patterns across the app and dashboard while adapting each experience to its users.
  • Built a shared design system with reusable components, typography, colors, and interaction states.
  • Adapted all the layouts and UI components across devices.

Project Impact

  • Brought vehicle tracking and management together in one mobile experience.
  • Made vehicle locations, activity, and alerts easy to identify through clear visual hierarchy.
  • Kept key management actions accessible for users on the go.
  • Provided administrators with a centralized fleet overview and management tools.
  • Unified platforms through a shared design system tailored to user needs.
