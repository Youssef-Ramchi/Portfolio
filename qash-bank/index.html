Qash Bank

Mobile app design for a
Simpler banking (Case Study).

UX Design, UI Design, Design System and Prototyping

Scroll to Explore

Qash is a mobile banking app concept focused on simplifying everyday financial tasks. Users can manage cards from different banks, track spending, make payments, and schedule transfers in one place. The experience combines clear navigation, consistent interfaces, and an AI assistant to help users manage their money with confidence.

View case study

My Role

My contributions and responsibilities in this project

UX UI Designer

Key Responsibilities

  • Defined the core user problem and goals around simplifying everyday banking.
  • Mapped user flows for managing cards, sending money, and scheduling transfers.
  • Organized the information architecture around key financial tasks.
  • Created wireframes to establish content priorities and navigation.
  • Applied clear visual hierarchy to balances, transactions, and primary actions.
  • Built a consistent design system with reusable components, typography, and colors.
  • Explored an AI assistant interface for accessing banking support and shortcuts.
  • Connected key screens into an interactive prototype to demonstrate user journeys.

Project Impact

  • Brought multi-bank card management and everyday banking into one app concept.
  • Prioritized essential financial information for an at-a-glance overview.
  • Simplified recipient setup by requesting only a name and RIB.
  • Made scheduled transfer details and statuses visible in dedicated views.
  • Established a consistent interface focused on familiarity and user control.
