Pralyne

Website design for an
Artisan pastry marketplace.

Strategy, UX design, UI Design and Usability Testing

Scroll to Explore

Pralyne is an online marketplace connecting customers with local pastry shops. It allows users to discover nearby stores, browse and personalize pastries, and order for pickup or delivery, while giving shop owners a dedicated space to showcase products and manage their business.

Live Website

My Role

My contributions and responsibilities in this project

UX UI Designer

Key Responsibilities

  • Conducted user research to understand customer needs and store management workflows.
  • Analyzed similar platforms to identify common patterns and design opportunities.
  • Designed Pralyne’s website from scratch, including the homepage, catalogs, product details, and partner pages.
  • Created browsing interfaces with search, filters, categories, and sorting.
  • Designed product customization interfaces with clear options and actions.
  • Designed an admin web app for managing stores, products, orders, customers, and discounts.
  • Organized dashboard metrics and recent orders into clear, readable layouts.
  • Conducted usability testing and refined the designs based on user feedback.

Project Impact

  • Created a cohesive digital experience reflecting Pralyne’s artisan pastry identity.
  • Provided clear paths for discovering stores and exploring products.
  • Presented product details and customization options in an organized layout.
  • Brought key management tasks together within a dedicated admin interface.
  • Delivered a consistent visual language across the website and admin web app.
